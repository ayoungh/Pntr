# Pntr

Pntr is an expressive, open-source Next.js website template with a painterly
editorial art direction. It is built with Next.js, TypeScript, and Tailwind CSS.

Created by Anthony Young.

[![Pntr website template preview](./public/pntr-showcase.png)](https://github.com/ayoungh/Pntr)

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customise it

- Update the page content in `app/page.tsx`.
- Adjust the palette and design tokens at the top of `app/globals.css`.
- Replace `public/pntr-hero.png` with your own 16:9 artwork.
